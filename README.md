# Custom Java Compiler

A from-scratch implementation of a Java compiler. This project was developed to explore the core concepts of compiler design, including lexical analysis, parsing, semantic analysis, and target code generation.

## Project Structure

The project is divided into several phases:
* **CompilersP1**: Lexical analysis and tokenization.
* **CompilersP2**: Syntax analysis and parser implementation.
* **CompilersP3**: Semantic analysis and abstract syntax tree (AST) generation.
* **CompilersP4**: Target code generation and optimization.

## Technologies Used
* Java
* Compiler Design Principles
